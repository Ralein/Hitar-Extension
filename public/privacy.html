Hitar Privacy Policy

Effective Date: August 2, 2026

1. Overview

Hitar is an open-source, cross-browser extension designed to translate web content in place using self-hostable LibreTranslate backends.

2. Data Handling

Hitar collects zero PII, zero telemetry, and zero browsing history. Webpage text extracted for translation is sent directly to your configured LibreTranslate endpoint.

3. Local Storage & Caching

Translations are stored locally in your browser's IndexedDB and storage.local. No data is sent to central extension servers.

4. Self-Hosting

Run your own private backend with Docker: docker run -p 5000:5000 libretranslate/libretranslate so text never leaves your local machine.
